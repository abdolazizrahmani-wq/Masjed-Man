# مسجد من — دارالقرآن کنخ

سامانه‌ی ثبت حضور، امتیازدهی و مسابقه‌ی ماهانه‌ی نوجوانان در مساجد (PWA فارسی، تقویم شمسی، کارکرد آفلاین).

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
npm run lint     # بررسی نوع‌ها (tsc)
```

برای ورود و ذخیره‌ی رمز، برنامه باید روی **HTTPS یا localhost** باز شود (Web Crypto).

## اولین اجرا

کاربر یا داده‌ی نمونه‌ای وجود ندارد. در اولین اجرا صفحه‌ی «راه‌اندازی» باز می‌شود و مدیر کل را می‌سازید.

## حالت ذخیره‌سازی (مهم)

- **بدون `VITE_API_URL` (پیش‌فرض):** همه‌ی داده در مرورگر همان دستگاه (`localStorage`/IndexedDB) می‌ماند.
  داده بین گوشی‌ها اشتراک ندارد و **هیچ احراز هویت واقعی‌ای وجود ندارد** (هر کسی با ابزار توسعه‌ی مرورگر می‌تواند داده‌ی خودش را تغییر دهد).
  فقط برای نمایش/آزمایش مناسب است.
- **با `VITE_API_URL`:** صف حضورهای آفلاین به `POST {VITE_API_URL}/attendances/sync` ارسال می‌شود
  (قرارداد درخواست/پاسخ در `src/utils/syncApi.ts`). این فقط همگام‌سازی است؛ ورود، دسترسی بر اساس نقش و ذخیره‌ی اصلی داده باید در سرور پیاده شود.

برای استفاده‌ی واقعی با اطلاعات دانش‌آموزان، یک بک‌اند (مثلاً Supabase یا Firebase با قوانین دسترسی بر اساس نقش) لازم است.
